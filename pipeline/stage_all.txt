# One array task = ONE MODEL's entire pipeline, run in order, then its
# activations and weights are deleted (see other/cleanup_model.py).
#   LANG -> PEREIRA expt2 -> PEREIRA expt3 -> MM -> [SEM] -> SPARSITY -> JOINT -> cleanup
# Grouping this way is what makes cleanup safe: SPARSITY and JOINT read LANG's
# activation cache, so it can only be freed once they are done -- guaranteed
# here because they are the same task.
#
# Format: MODEL <model> <nw_lang> <nw_pereira> <nw_sem> [pereira flags...]
# Ordered longest-first: with a concurrency cap this shortens the makespan.
